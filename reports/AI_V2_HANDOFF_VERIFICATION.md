# AI v2 handoff and user synthesis evidence

The user supplied v2 holdout screenshots (210/210 windows, 10 captures, baseline also 100%) and synthesis screenshots (445 logic,246 registers,0 latches,0 BSRAM,1 DSP,103 standalone I/O,50MHz analysis clock,56.4MHz estimated synthesis Fmax). These are user-reported; actual v2 model/PCAP/Gowin report files have not yet been uploaded. Do not label them independently reproduced or routed/board measurements. Details: `ai_part2/handoff/GOWIN_SYNTHESIS_V2_USER.md`.

`tools/make_handoff_v2.py` runs on the user's existing kit. It verifies the frozen model/metrics hashes; validates HEX and all vectors against the integer model; compares exported reference files, embedded-weight RTL, firmware quantization and vectors against that model; requires the matching RTL simulation log; and recomputes the existing holdout without fitting to check its stored metrics. It packages the consistent project, model, test evidence, raw-feature/interface specs, dynamically generated firmware/feature handoff and arithmetic examples with SHA256 for every file. It refuses stale exports, changed metrics, missing simulation evidence and overwriting an existing bundle. PCAPs and executable simulation binaries are not packaged. User synthesis figures are explicitly labeled as screenshots without a project hash binding.

Cloud verification: three new consistency tests passed using artificial dataset fixtures. Full suite: 48 tests passed, including existing loopback MQTT and namespace lifecycle mocks. An end-to-end CLI smoke test packaged a 31-file bundle from the earlier artificial model with actual Icarus simulation evidence; this is not a new network accuracy result. No actual v2 model from the user, vendor synthesis, routed timing, firmware integration or real packet blocking was tested in the cloud.
